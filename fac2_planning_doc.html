1. 고객사 접수

고객사 발주서(PO)를 접수하고 시스템에 등록하는 단계
1) 고객사 접수를 어떻게 받을지
고객사 PO를 이메일 또는 EDI로 수신한다. 수신 즉시 문서번호·고객사명·대상 모델·수량·발주일을 시스템에 등록하고, 원본 PO 파일을 첨부하여 보관한다(SQ 심사 근거자료).
접수 PO 예시
문서번호고객사발주일대상 모델총 수량
PO-2026-0823-CN8OO Motors2026-08-20CN8 S / CN8 C / CN8 H

2. 2공장에서는 어떻게 받을지

접수된 PO를 2공장이 확인하고 시스템에 정식 등록하는 절차
PO 수신 → 2공장 담당자 확인 → 시스템 등록 → 가용자산분석 대기 → 3단계 진입
2공장 담당자가 수량·모델·납기를 1차 확인한 뒤 시스템에 등록하며, 등록 즉시 상태가 '가용자산분석 대기'로 전환되어 3단계로 자동 연결된다.

3. 2공장 가용자산 분석

수량 · 인력 · 설비 CAPA를 한 시트에서 통합 분석하여 생산 가능 여부를 판정
1) 수량을 받으면 어떻게 분석하는지
모델별 요청수량을 계획기간(일)으로 나누어 일일 필요 CAPA를 산출하고, 해당 모델을 생산할 수 있는 가동가능 설비의 CAPA 합계와 비교한다.
2) 인력은 어떻게 관리할지
주간조·야간조별 필요인원 대비 배치인원을 확인한다. 부족 인원이 있는 조는 별도 표기하여 4단계 계획수립 시 잔업·지원 배치 여부를 검토한다.
3) 설비 CAPA는 어떻게 할지
DC1~DC23 중 해당 모델에 대응 가능하면서 상태가 '가동가능'인 설비만 CAPA 계산에 포함한다. 정비중·고장 설비는 제외하여 실제 생산 가능한 CAPA만 반영한다.
4) 이걸 한 시트에서 분석하는 것
아래 표 하나에 요청수량·가동설비·설비CAPA·필요CAPA·소요일수·인력영향·종합판정을 모두 배치하여, 별도 화면 전환 없이 한 번에 확인할 수 있도록 구성했다.
통합 가용자산분석 시트
모델요청수량가동 설비 설비 CAPA/일필요 CAPA/일 소요일수인력 영향종합판정
가능·여유 — 필요CAPA/일 ≤ 설비CAPA/일 주의·증산검토 — 설비CAPA/일의 130% 이내 초과 불가·증산필요 — 설비CAPA/일의 130% 초과
설비 CAPA 현황 (DC1~DC23 중 발췌)
설비상태대응 모델CAPA/일
인력 배치 현황
조필요인원배치인원상태

4. 2공장 계획수립

3번 가용자산분석 결과를 기반으로 생산계획(안)을 수립
1) 3번에서 가용 자산을 분석한 자료를 기반으로 계획수립
종합판정이 '불가' 또는 '주의'인 모델을 생산 우선순위 1순위로 배치하여 선제적으로 조치하고, 여유가 있는 모델은 후순위로 정렬한다.

5. 2공장 → 1공장 발주 진행

4번에서 확정된 계획을 1공장에 통보
4번에서 확정된 생산순서와 수량을 1공장에 통보한다. 통보 시각은 자동 기록되며, 이 시점부터 Box 2(1공장 생산계획)가 시작된다.
